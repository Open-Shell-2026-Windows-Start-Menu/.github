# Project Overview

Open-Shell is a collection of Windows utilities designed to bring back classic Windows interface features and provide additional customization options.

The project is a continuation of Classic Shell and focuses primarily on the Start menu and Windows Explorer. It allows users to choose from classic-style Start menu layouts and customize various aspects of the Windows desktop interface.

Open-Shell supports Windows 7, 8, 8.1, 10, and 11. The project also supports Windows on ARM starting with version 4.4.196.

---

# Classic Start Menu

Open-Shell provides alternative Start menu layouts inspired by earlier versions of Windows.

Users can customize the Start menu appearance, menu behavior, shortcuts, icons, search functionality, and other interface elements according to their preferred desktop workflow.

The customization options allow users to create a more traditional Windows-style Start menu while continuing to use modern Windows versions.

---

# Windows Explorer Integration

Open-Shell includes utilities for Windows Explorer that add additional interface functionality.

Available features include an Explorer toolbar and an Explorer status bar that can display information such as file size and available disk space.

The project also contains classic interface components for supported Windows versions.

---

# Customization & Themes

Open-Shell provides numerous settings for adjusting the Start menu and related interface components.

Users can customize menu styles, Start buttons, icons, colors, menu behavior, and other visual elements.

Custom Start buttons and skins can be used to change the appearance of the interface while retaining the underlying Windows desktop environment.

# 2026 Updates

The Open-Shell project continued development throughout 2026.

The **4.4.201** release is currently listed as a pre-release and includes:

* Horizontal Start button offset configuration.
* Improved screen-reader support.
* Improved keyboard accessibility.
* High Contrast accessibility improvements.

The latest release listed as **4.4.200** includes automatic restart sign-on support and a fix for the `properties` command.

Version **4.4.196** introduced Windows ARM64 support and improved compatibility with ExplorerPatcher.

| Component        | Minimum Practical Configuration         |
| ---------------- | --------------------------------------- |
| Operating System | Windows 7 / 8 / 8.1 / 10 / 11           |
| Processor        | 1 GHz or faster CPU                     |

| Storage          | Approximately 50 MB for the application |
| Graphics         | Integrated graphics supported           |
| Display          | 1024×768 or higher                      |
| Architecture     | x86, x64, or ARM64                      |
